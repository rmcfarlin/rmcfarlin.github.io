Small status pill in uppercase mono. Tones carry financial meaning.

```jsx
<Badge tone="positive" dot>On track</Badge>
<Badge tone="negative">Over budget</Badge>
<Badge tone="caution">Pending review</Badge>
<Badge tone="forest" variant="solid">Audited</Badge>
```

Tones: `positive | negative | caution | info | neutral | forest | brass`. Variants: `soft` (washed, default), `solid`, `outline`. Add `dot` for a status indicator dot.
