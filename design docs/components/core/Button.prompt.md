Primary action control for the McFarlin system — forest-green primary by default; use `brass` only for a single high-emphasis CTA per view.

```jsx
<Button>Book a consultation</Button>
<Button variant="secondary">Download summary</Button>
<Button variant="ghost">Learn more</Button>
<Button variant="brass" size="lg">Request engagement</Button>
```

Variants: `primary` (forest), `secondary` (outlined neutral), `ghost` (quiet, moss text), `brass` (accent — sparing use). Sizes `sm | md | lg`. Pass `iconLeft`/`iconRight` for icons, `block` for full width, `as="a"` + `href` for links.
