Surface container — the default grouping unit for content, metrics, and tables.

```jsx
<Card pad="lg">
  <h3>Engagement summary</h3>
  <p>Q3 financial review and forward model.</p>
</Card>
<Card tone="forest">Dark feature panel</Card>
<Card tone="sunken" elevation="flat">Recessed well</Card>
```

Tones: `surface` (white, default), `sunken` (warm recessed), `forest` (dark feature panel, light text). Control inner padding with `pad` and depth with `elevation`.
